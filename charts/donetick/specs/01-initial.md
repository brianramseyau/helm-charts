# Donetick Helm Chart Initial Specification

## Scope

Create a Helm chart in `charts/donetick` for deploying Donetick with opinionated defaults and optional storage/database modes.

## Requirements Implemented

1. Chart name: `donetick` under `charts/`.
2. Default namespace value: `donetick` via `namespaceOverride`.
3. App image:
   - Repository: `donetick/donetick`
   - Tag: `v0.1.74`
4. Health checks:
   - Docker healthcheck endpoint `/api/v1/health` ported to Kubernetes probes.
   - Probe timeout values are set to 5 seconds or greater.
5. Database options:
   - Default: Bitnami PostgreSQL dependency enabled.
   - Dependency source: `oci://registry-1.docker.io/bitnamicharts`
   - Dependency version: `16.7.27`
   - Optional SQLite mode with optional PVC support.
6. Storage options:
   - Local storage mode with optional PVC mounted at `/app/assets`.
   - Remote storage mode for S3-compatible providers.
7. MinIO option:
   - Optional additional deployment disabled by default.
   - Image: `quay.io/minio/minio:RELEASE.2025-04-22T22-12-26Z`.
   - Optional admin UI ingress disabled by default.
8. Donetick configuration:
   - Generated from the selfhosted-style configuration structure.
   - Mounted to `/config/selfhosted.yaml` as a configmap.
   - config.jwt.secret should be autogenerated unless explicitly passed through in values.yaml.

## Notes

- PostgreSQL is enabled by default to satisfy the default deployment requirement.
- MinIO remains disabled by default and can be enabled for self-contained remote object storage.
- SQLite mode is intended for users who explicitly disable PostgreSQL.
